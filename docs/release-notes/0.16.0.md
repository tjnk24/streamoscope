> [!IMPORTANT]
> **Coming from 0.10.0 or older, and an update said the new version didn't start and went back? Run the installer once.** As in 0.10.1 and later: on some PCs OBS opens the dock later than old versions were willing to wait. Close OBS and run [streamoscope-setup-0.16.0.exe](https://github.com/tjnk24/streamoscope/releases/download/v0.16.0/streamoscope-setup-0.16.0.exe) over your installation: it installs without that check. Your settings, the journal and OBS stay as they are. If your updates go through fine, skip it.

The workshop compared its numbers with Task Manager and lost the argument. So now they agree.

- **CPU and GPU, counted like Task Manager.** The CPU row shows the load of the whole computer, not just OBS, and the GPU row takes the busiest part of the card, whatever it is busy with. If the dock and Task Manager disagree now, blame the refresh rate. The CPU row needs the Lua bridge and stays hidden without it.
- **The OBS card is now "OBS and PC".** OBS on the left, the computer on the right; in a narrow dock it is one column, as before.
- **Shorter hints.** The rows that explain themselves lost theirs, and the bitrate hint moved from the graph to a question mark next to kbps.
- **Manual installs update themselves.** Every release now has `streamoscope-portable-0.16.0.zip`: the same folder the installer makes, without the Windows Apps entry and the OBS setup. Unpack it into a folder you can write to, and updates and the rollback work as after the installer. On the plain `streamoscope-<version>.zip`? Delete its files, unpack the portable archive into the same folder and restart OBS: the paths stay, and so do the settings. Details in the [README](https://github.com/tjnk24/streamoscope#-manual--portable-installation).
- **Proof of origin.** The installer, the archive and `compatibility.json` now come with a GitHub build attestation: the file was built by this repository's release workflow, not on someone's laptop. How to check: [Verify downloads](https://github.com/tjnk24/streamoscope#-verify-downloads).
- Under the hood the dock got a faster build and a pile of end-to-end tests. You won't see either, which is the point.

Запустите установщик один раз.** Как и начиная с 0.10.1: на некоторых ПК OBS открывает док позже, чем готовы были ждать старые версии. Закройте OBS и запустите поверх установленной программы [streamoscope-setup-0.16.0.exe](https://github.com/tjnk24/streamoscope/releases/download/v0.16.0/streamoscope-setup-0.16.0.exe): он ставит версию без этой проверки. Настройки, журнал и OBS останутся как есть. Если обновления у вас проходят нормально, этот шаг не нужен.

Мастерская сверила свои цифры с Диспетчером задач и проиграла спор. Теперь они сходятся.

- **CPU и видеокарта — как в Диспетчере задач.** Строка CPU показывает загрузку всего компьютера, а не только OBS, а строка видеокарты берёт самую занятую её часть, чем бы та ни была занята. Если панель и Диспетчер всё же расходятся — виновата частота обновления. Строке CPU нужен Lua-мост, без него она скрыта.
- **Карточка OBS теперь «OBS и компьютер».** Слева OBS, справа компьютер; в узкой панели — одна колонка, как раньше.
- **Подсказки короче.** У строк, которые объясняют себя сами, подсказок больше нет, а подсказка к битрейту переехала с графика на вопросик рядом с kbps.
- **Ручная установка обновляется сама.** У каждого выпуска теперь есть `streamoscope-portable-0.16.0.zip`: та же папка, что делает установщик, только без записи в «Приложениях» Windows и без настройки OBS. Распакуйте его в папку, куда можно писать, и обновления с откатом заработают, как после установщика. Стоит обычный `streamoscope-<версия>.zip`? Удалите его файлы, распакуйте портативный архив в ту же папку и перезапустите OBS: пути останутся прежними, настройки тоже. Подробнее — в [README](https://github.com/tjnk24/streamoscope#-manual--portable-installation).
- **Подтверждение происхождения.** Установщик, архив и `compatibility.json` теперь идут с аттестацией сборки GitHub: файл собран процессом выпуска этого репозитория, а не на чьём-то ноутбуке. Как проверить — [Verify downloads](https://github.com/tjnk24/streamoscope#-verify-downloads).
- Под капотом у панели теперь сборка побыстрее и гора сквозных тестов. Ни того, ни другого вы не увидите — в этом и смысл.
