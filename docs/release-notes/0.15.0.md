Run the installer once.** As in 0.10.1 and later: on some PCs OBS opens the dock later than old versions were willing to wait. Close OBS and run [streamoscope-setup-0.15.0.exe](https://github.com/tjnk24/streamoscope/releases/download/v0.15.0/streamoscope-setup-0.15.0.exe) over your installation: it installs without that check. The workshop went on a language course and came back with thirteen more. The accent is still there.

- **Ukrainian, Polish, French, Italian, Dutch, Turkish, Vietnamese, Indonesian, Thai, Japanese, Korean and Chinese, Simplified and Traditional.** The dock speaks them all, and the menu names in its hints match your OBS word for word. Korean and Japanese are here for the CHZZK, SOOP and niconico crowd, whom the dock already knew by server.
- If you never picked a language, the dock follows OBS, so an OBS in any of these languages gets its own right away. Changed your mind? **Settings → Display → Interface language**.
- The installer speaks the new languages too, except Chinese, Vietnamese and Indonesian: Inno Setup has no ready translation for those, so the installer stays in English there. A background update brings the dock, so the installer only matters for a fresh install.
- Release notes stay in English and Russian.
- Native speakers who spot a clumsy phrase: an issue on GitHub is welcome.
