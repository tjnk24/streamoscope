# Обновлятор: как устроен

Что делает мост и панель - `bridge.md` и `dock.md`, правила PowerShell - `.claude/rules/windows/powershell.md`.

- **Обновлятор - `installer/updater/Update-Widget.ps1`** с функциями в `installer/updater/UpdateWidget/` (`download/`, `versions/`, `rollback/`), входит в выпуск и лежит в `versions/<версия>/updater`, поэтому обновляется вместе с программой. `minisign.exe` - только в `{app}\updater`, его кладёт установщик: скачанные программы мы не запускаем (решение пользователя). Папку установки и `minisign.exe` скрипт находит от своего положения. Запускает его мост: `-Version X.Y.Z` (кнопка «Обновить») или `-Auto` (фоновая проверка), остальные параметры по умолчанию (адреса выпусков, публичный ключ строкой - тест сверяет его с `minisign.pub`, файл статуса `%LOCALAPPDATA%\streamoscope\update-status.json`). `-Auto` (`Invoke-AutoUpdate`) с пониженным приоритетом: не чаще раза в `AutoCheckMinIntervalHours` по метке `update-check.stamp` (неудачный запрос меткой не считается) поправляет `DisplayVersion` в «Приложениях» (после отката он отстаёт) и берёт из API GitHub тег и дату последнего выпуска и решает (`Get-AutoUpdateAction`): не новее - `upToDate`, другая major-версия - `manualOnly`, не новее откаченной - `rolledBack`, выпуск моложе `AutoInstallDelayHours` (48 ч, чтобы успеть отозвать плохой) - `tooFresh`, иначе ставит. Порядок установки (`Invoke-UpdateWidget`): блокировка `update-status.json.lock` (второй запуск - `busy`) -> версия `X.Y.Z` и новее текущей из `current-version.js` (та же самая - сразу `done`, старше - `notNewer`) -> скачать и проверить подпись `compatibility.json`, сверить в нём версию и минимальную версию OBS с `obs64.exe` (`Get-ObsVersion` через `Find-ObsDirectory` из `ConfigureObs` своей версии, `versions\<версия>\ConfigureObs`; в версиях, собранных до 0.7.0, его там нет - тогда из `{app}\ConfigureObs`) -> скачать `streamoscope-<версия>.zip` с процентами (любое скачивание - `Get-UpdateFile`: `DownloadTimeoutMilliseconds`, 30 с, на ответ и на каждое чтение, не дольше `DownloadDeadlineMilliseconds`, 10 минут, целиком, а длина должна совпасть с `Content-Length`; иначе ошибка `network`, а не `signature`), проверить подпись -> распаковать в `versions/staging-<версия>`, проверить состав (`RequiredPackageFiles`) и версию внутри, переместить в `versions/<версия>` (`Expand-UpdatePackage`) -> записать `update-trial.txt` (`Write-UpdateTrial`) -> атомарно заменить `current-version.js` (`Set-CurrentVersion`, `File.Replace`): всё, что случилось раньше, текущую версию не трогает -> стереть `rolled-back-version.txt`, оставить три новые версии и версию для отката (`Remove-OldVersions`), обновить `DisplayVersion` в «Приложениях» -> `done`. Статус - JSON `{version, stage, percent, error, updated}`, этапы `preparing`, `downloading`, `verifying`, `installing`, `done`, `failed`; коды ошибок `invalidVersion`, `notNewer`, `network`, `signature`, `incompatible`, `install`, `unexpected`. Временные файлы - `%TEMP%\streamoscope-update-<версия>`, удаляются всегда. Тесты (`Update-Widget.Tests.ps1`) - на поддельном выпуске в `TestDrive` по `file:///` с временными ключами, версия OBS и запись в реестр подменяются `Mock`; `npm run test:installer` сначала достаёт `minisign.exe` (`scripts/buildInstaller/fetchMinisign.ts`).
