# Тесты Pester 5+

- `Mock` не видит отдельный процесс: то, что скрипт запускает сам через новый `powershell.exe`, подменить нельзя. Такой тест пропускаем, когда окружение ему мешает.
- Функций-помощников в `*.Tests.ps1` нет: каждая - файл `Глагол-Существительное.ps1` в `tests/helpers/` с подпапками по тому, чьи это помощники; тест подключает их в `BeforeAll`. Папку не называем `release/`: такие скрывает `.gitignore`.
- Образцы - выдуманные данные с настоящей структурой, без личных путей и паролей; `.gitattributes` держит их байты как есть (`-text`). Новый случай в чужом формате - сначала образец и тест, потом правка скрипта.
- Только синтаксис, который есть и в Pester 5, и в 6: в GitHub Actions на Windows стоит пятый.
