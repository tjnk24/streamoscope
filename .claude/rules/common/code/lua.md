# Lua

- **`main.lua` - только точка входа**: подключает модули и отвечает хозяину скрипта (загрузка, выгрузка, события), логики в нём нет.
- **Модули - в папке проекта**, подключаются `require` с её именем впереди (`require('<папка>.<модуль>')`): без префикса можно найти чужой файл (`require('json')`).
- **Источник с состоянием - класс, без состояния - модуль.**
  - Класс: таблица с `Class.__index = Class`, конструктор `Class.new()` возвращает `setmetatable({...}, Class)`, открытые методы - `function Class:method()`, состояние - поля `self`. Приватные помощники - `local function helper(self, ...)` в его файле (методы с `_` снаружи видно).
  - Конструктор не падает, если источник недоступен (не Windows, нет DLL): объект создаётся, `sample`/`read` возвращают `nil`.
  - Экземпляры создаёт загрузка скрипта, закрывают выгрузка и выключение; остальным модулям они приходят параметром `sources`.
  - Модуль - таблица функций (`targets.read`, `json.encode`), его `local`-функции и константы приватные.
  - Файл - snake_case, переменная класса при подключении - PascalCase (`local Gpu = require(...)`), модуля - snake_case.
- **Константы - только в `consts.lua`** (корень папки модулей, один на скрипт), обращение `consts.ИМЯ`: числа WinAPI, шаблоны, пути, GUID. Непонятное без контекста имя - с префиксом модуля (`JSON_ARRAY_METATABLE`). Таблица модуля (`local gpu_names = {}`), класс и `__index` - не константы. Исключения - только файлы, названные в правилах проекта.
- **`ffi.cdef` - в модуле, который его использует, в `pcall`**: повторное объявление типа - ошибка. Глобальных переменных не заводим.
- **Пути и переменные окружения в Windows - только W-функциями**: `os.getenv`, `io.open`, `os.execute` работают в ANSI и ломаются на кириллице в имени пользователя, `os.execute` ещё и мелькает консолью.
- **JSON не склеиваем строками**: таблица и `encode`. Пустой массив и явный `null` - особыми значениями модуля JSON (пустая таблица иначе станет `{}`), поле с `nil` в JSON не попадает.
- **Ошибка одного источника не роняет скрипт**: создание источников и каждое чтение - в `pcall`, без данных поле пропадает.
- **Имена - snake_case**, остальные правила имён и «никаких комментариев» - `code/general.md`.

## Скрипты OBS

- **`error()` в OBS ничего не бросает** - только пишет в журнал скриптов. Остановить загрузку файла - `error(сообщение, 0)` и сразу `return false`; ошибку для `pcall` бросает сама Lua (`assert`), а не `error`.
- **`obslua` - через `local obs = obslua`** в каждом модуле, которому он нужен.
