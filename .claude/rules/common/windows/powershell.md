# PowerShell

- **Одна функция - один файл** `Глагол-Существительное.ps1` (одобренные глаголы PowerShell), переменные - camelCase. Правки текста - чистые функции «текст на входе - текст на выходе», файлы читают и пишут только отдельные функции для этого.
- **Чужие файлы настроек не переписываем целиком**: PowerShell 5.1 в `ConvertFrom-Json`/`ConvertTo-Json` меняет числа, экранирование и вложенность. Правка вставляет или заменяет только нужный кусок, в ini - одну строку. Остальное - байт в байт, BOM и переводы строк сохраняются. Большой JSON рекурсивно не разбираем: в 5.1 это ~19 с на мегабайт.
- **`PSModulePath` сбрасываем в начале точек входа** на пути Windows PowerShell: `powershell.exe`, запущенный из PowerShell 7 (терминал, шаг GitHub Actions по умолчанию), наследует модули седьмой версии и теряет команды вроде `Get-FileHash`.
- **Константы - в `consts.ps1` своей программы** (`$script:Имя = ...`). Лежат рядом с функциями, подключаются тем же `Get-ChildItem *.ps1`. В файлах функций `$script:`-констант нет; переменная состояния - не константа, остаётся у своей функции.
- **`$PSScriptRoot` - не в значениях параметров по умолчанию**: при `-File` PowerShell 5.1 его там не заполняет. Папка скрипта - в теле: `Split-Path -Parent $MyInvocation.MyCommand.Path`.
- **Внешние программы при `$ErrorActionPreference = 'Stop'`** не перенаправляем `2>&1`: в 5.1 их поток ошибок становится исключением. В функции, которая вызывает программу, - `$ErrorActionPreference = 'Continue'`, поток ошибок - `2>$null`, решение - по `$LASTEXITCODE`.
- **`.ps1` - только ASCII**: 5.1 читает файл без BOM в ANSI, кириллица ломается. Тексты для пользователя показывает вызывающая программа (установщик), а не скрипт.
