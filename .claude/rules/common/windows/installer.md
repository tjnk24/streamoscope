# Установщик (Inno Setup)

- **Без прав администратора** (`PrivilegesRequired=lowest`): ставится в `%LOCALAPPDATA%\Programs\<программа>` без выбора папки, запись в «Приложениях» с деинсталлятором - в HKCU. `AppId` не меняем никогда: по нему новая версия ставится поверх старой.
- **Тексты - `[CustomMessages]` на всех языках установщика**, новая строка - во все сразу. Свой текст стандартного окна Inno - в `[Messages]` с тем же префиксом языка (`ru.SetupAppRunningError`).
  - Названий кнопок Windows («Повторить», «Отмена») в текстах нет: их подписывает Windows.
  - `.iss` - UTF-8 с BOM; сообщения - `SuppressibleMsgBox`, чтобы тихая установка (`/VERYSILENT /SUPPRESSMSGBOXES`) не зависала.
- **Живую установку запускает пользователь из Проводника, а не Claude.** Claude Desktop - пакет MSIX, его процессы работают в контейнере: записи в HKCU и новые папки в `%AppData%`/`%LocalAppData%` уходят в реестр пакета и `LocalCache` (`%LOCALAPPDATA%\Packages\Claude_*`). Такая установка не появится в «Программах и компонентах», журнал и копии окажутся в `LocalCache`, а изменения уже существующих файлов (настройки программ, `%LOCALAPPDATA%\Programs`) - настоящие. Удалять её - её же деинсталлятором из той же среды. Тихим проверкам на копии настроек это не мешает.
